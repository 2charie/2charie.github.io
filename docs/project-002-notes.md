# Project 02 제작 및 검수 기록

2026-11-09. 로컬 소스 기준으로 project-002를 실제 공공 계약 모니터링 시스템 기획 사례로 교체했습니다. GitHub에서 이전 소스를 가져오거나 기존 작업을 초기화하지 않았으며, 커밋·푸시·배포도 수행하지 않았습니다.

## 콘텐츠 구성

- Hero: 제공된 제목·부제·담당 영역과 진행 중 상태. 미확인 기간·정량 성과는 기재하지 않음.
- Overview: 기업별 현황과 관리 기준, 위험신호의 근거를 연결하는 목적.
- Problem Definition: 업무 문제 4개를 필요한 기능과 연결.
- Planning Process: 요구사항 → 데이터·집계 → 모니터링 → IA·화면 → HTML 프로토타입·검수의 5단계.
- Key Design Decisions: 기업 중심 정보구조, 신호와 근거, 집계 기준 설명, 단계적 탐색의 4가지 판단과 산출물.
- Results & Reflection: 수행한 기획 업무와 산출물, 현재 진행 상태 구분. 출시·전체 기능 구현 완료나 수치로 입증되지 않은 성과를 주장하지 않음.

시각 자료는 관련 설계 판단 아래에 배치했으며 별도 이미지 갤러리를 만들지 않았습니다.

## 가상 데이터

모든 기업·부서·계약·금액과 화면 상태는 설명용으로 만든 예시입니다.

| 예시 기업 | 계약 건수 | 금액(만 원) | 계약별 금액(만 원) |
| --- | --- | --- | --- |
| 가상 기업 A | 3 | 2,400 | 900 + 800 + 700 |
| 가상 기업 B | 2 | 1,600 | 1,000 + 600 |
| 가상 기업 C | 2 | 1,200 | 700 + 500 |
| 합계 | 7 | 5,200 | 화면에서 계약 배열로부터 계산 |

포트폴리오 설명용 예시 화면·가상 데이터라는 안내와 실제 운영 디자인·데이터와 다르다는 문구를 화면에 명시했습니다. 상태 표시는 예시이며 실제 임계값·위험점수·내부 예외 로직을 반영하지 않았습니다. 이상징후를 위법·부정행위 확정으로 표현하지 않았습니다.
