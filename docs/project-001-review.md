## 수치 대조

- 표 1: ATQ-P 표준 106.78 (9.10), 인상관리 131.56 (9.86), 왜곡 24.78 (6.84).
- 표 1: ATQ-N 표준 129.00 (10.30), 인상관리 140.89 (6.98), 왜곡 11.90 (5.87).
- t = 6.13, p < .001. 차트 축 0–30점. 막대 길이는 각각 24.78/30, 11.90/30으로 계산하며 원자료·CI는 생성하지 않음.
- 모델 1: 사회적 바람직성 B 1.062, β .452, t 3.000, p < .01; R² .204, 수정 R² .182, F 9 (p < .01).
- 모델 2: 사회적 바람직성 B .225, β .096, t .673, p .506(5쪽 결론); 검사 유형 B −11.403, β −.658, t −4.609, p < .001; R² .510, 수정 R² .482, ΔR² .306(p < .001), F 17.72(p < .001).
- 모델 3: 사회적 바람직성 B .166, β .091, t .303; 검사 유형 B −12.307, β −.660, t −1.748; 상호작용 B .096, β .021, t .138. 해당 계수는 원문에서 유의하지 않음. R² .510, 수정 R² .466, ΔR² .00, F 11.48(p < .001). 정확한 p값은 만들지 않음.
- 모형 전체 F가 유의하더라도 상호작용이 유의하다는 뜻으로 해석하지 않음.

## 원문에서 확인이 필요한 사항

1. **ATQ-N 점수 방향:** 2쪽은 부정적 척도에서 점수 축소를 설명하지만 표 1에서는 129.00 → 140.89로 증가함. 역채점·차이 점수 부호 처리 설명이 충분하지 않음. 원문 값을 유지하고 사이트에 해석 주의를 표시.
2. **표시 평균의 차이:** 140.89 − 129.00 = 11.89이지만 표의 왜곡 평균은 11.90. 반올림 전 평균에 의한 차이일 수 있으나 원자료가 없어 확정 불가. 보고값 11.90을 유지.
3. **집단·회기 구성:** 동일 참가자의 지시문별 차이를 설명하면서 2쪽에서는 인상관리 참가자 남 8명·여 12명, 표준 참가자 남 11명·여 9명으로 기재. 최종 검사별 인원과 배정 방식도 불명확. 두 독립 지시문 집단으로 재해석하거나 무작위 배정을 주장하지 않음.
4. **다른 연구 변수의 혼입:** 4쪽 결과 문장에 우울·학습활동·성별이 등장. 실제 표 2의 사회적 바람직성·검사 유형 해석과 맞지 않는 편집상 오류로 보이나 원문을 수정하지 않음.
5. **초록과 최종 해석:** 초록의 유의한 예측은 단순 회귀에 해당. 본문에서는 검사 유형 추가 후 비유의. 사이트는 모형별로 구분하며 6쪽의 '거짓 효과'를 확정적인 허위 상관이나 인과 결론으로 옮기지 않음.
6. **척도 개발연도:** SDS 설명은 김용석(2018), 참고문헌은 김용석(2010)으로 기재. 사이트에서는 개발연도를 생략. 다른 참고문헌의 오탈자는 이 프로젝트에서 재사용하지 않음.
7. **모델 3 코딩·반올림:** 더미 코딩 기준과 중심화 여부를 확인할 수 없음. B·β·t는 원문 값 그대로이며 재추정하지 않음. ΔR² .00은 표의 표시 정밀도이며 효과가 정확히 0이라는 주장으로 확대하지 않음.
8. **기타 미확인 정보:** 수행 연월, 개인 담당 범위, 회기 간격, 극단값 기준을 임의로 기재하지 않음. 대표 그래픽은 개념도이며 관측 자료나 연구 결과가 아님을 대체 텍스트와 이미지에 명시.
